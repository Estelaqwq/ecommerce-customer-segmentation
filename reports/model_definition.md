# 评分与分层规则

## 特征

正向归一化为 `(值 − 最小值) / (最大值 − 最小值) × 100`；反向归一化为 `100 − 正向得分`。常数列取 50。所有范围与分位数基于当前分析样本计算。

| 特征 | 定义 |
|---|---|
| R | 最近登录天数的反向得分，表示近期活跃度 |
| F | 购买频次的正向得分 |
| M | 累计消费的正向得分 |
| I | 浏览时长与浏览页数正向得分的均值 |
| Friction | 浏览页数 / (购买频次 + 1)，仅作规则特征，不代表已识别的购买阻力 |
| Income_Level | 收入的 33%、66% 分位数切分为低、中、高；低档含下边界，中档含上边界 |
| L_Score | 已订阅且最近登录 <7 天为 3；未订阅且最近登录 <7 天为 2；否则为 1，仅保留作描述，未用于综合分 |
| RFM_Score | 0.2R + 0.3F + 0.5M |
| Final_Score | RFM_Score × (1 + wI/100)，默认 w=0.2；综合分可以超过 100 |

## 基础标签

从上至下检查，取第一个满足的条件；未满足者为“一般用户”。

| 顺序 | 条件 | 基础标签 |
|---|---|---|
| 1 | R>60，F>60，M>60 | 重要价值用户 |
| 2 | R>60，M>60，F<40 | 重要发展用户 |
| 3 | R<40，F>60，M>60 | 重要保持用户 |
| 4 | R<40，M>60 | 重要挽留用户 |
| 5 | R>60，F>40，M<40 | 一般发展用户 |
| 6 | R>60，F<40，M<40 | 一般维持用户 |
| 7 | R<40，F<40，M<40 | 低价值用户 |

## 细分标签

在基础标签之上，再按以下顺序判断，取第一个满足的条件；全部不满足则保留基础标签。边界采用严格大于或小于，不把等于阈值的记录自动归入。

| 顺序 | 条件 | 细分标签 |
|---|---|---|
| 1 | 基础标签为低价值或一般维持；高收入；I>60 | 高潜沉睡用户 |
| 2 | 高收入；I>70；F<40；M<50 | 高收入高浏览低购买用户 |
| 3 | 基础标签为一般维持或一般发展；I>80；Friction 高于样本的 60% 分位数 | 犹豫型潜力用户 |
| 4 | 低收入；I>70；F<40 | 隐形活跃者 |
| 5 | 高收入；R<40；M>50 | 高收入消费较高低活跃用户 |
| 6 | M>70；F>70；I>60 | 核心VIP |
| 7 | 低收入；I<40；M<40 | 低收入低浏览低消费用户 |

“沉睡”“犹豫”等名称是运营假设标签，不能据此判断用户真实意图。标签的具体含义以条件为准。

## 展示组别

- 核心：核心VIP、重要价值用户。
- 潜力：高潜沉睡用户、高收入高浏览低购买用户、犹豫型潜力用户、高收入消费较高低活跃用户。
- 其他：剩余所有标签。

## 比较时固定什么

- 数据口径比较：排除待核对记录后，重新计算全部特征和阈值，对共同保留的用户比较前后标签。
- 权重比较：固定全量 1,000 人和前 200 人名额，仅改变 w。得分相同按字符串用户 ID 升序排序。改变 w 不改变规则标签。
- 收益策略比较：不同策略中的同类用户使用相同响应率。人数和成本同时展示，响应率仍属于假设。
