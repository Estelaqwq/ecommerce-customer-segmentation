# Power BI 单页报告

使用 Power BI Desktop 打开 [电商用户分析_单页版.pbip](CustomerAnalysis/电商用户分析_单页版.pbip)。整个 `CustomerAnalysis` 文件夹需要一起保留，不能只复制 `.pbip` 文件。

项目使用原生可编辑图表，数据嵌入语义模型，打开时不依赖本机原来的 CSV 路径。首次打开可能需要刷新或应用模型更改，随后可另存为 `.pbix`。

报告包括用户规模与消费指标、人群构成、消费和评分分布、群体对比、浏览权重比较与收益情景，整体为蓝白色单页布局。

## 口径

用户主表是全量 1,000 人的已计算结果。“待核对”筛选只筛选已评分记录，不会重新计算分层阈值。需要比较排除 85 人后重算的标签，请查看 HTML 看板的样本切换或 [分析报告](../reports/project_report.md)。

权重比较和收益情景为独立分析表，展示预先计算的情景，不承诺随所有用户筛选器重新计算。收益情景不是活动实测。

## 更新

此文件是随作品交付的可编辑快照，`run_analysis.py` 不会改写 Power BI 模型。调整评分或情景参数后，可以在 Power BI 中重新导入 `outputs/` 的对应结果并更新页面。

已检查项目目录、报告 JSON 和模型引用；当前整理版本未重新在 Power BI Desktop 中完成逐项显示检查。打开后若 Desktop 提示版本兼容性问题，请保留原项目，在本机支持 PBIP 的版本中另存一份。
