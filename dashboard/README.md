# HTML 交互看板

打开本目录的 **`index.html`**。全部数据、样式和图表库已经打包在这个文件内，双击后可在 Edge 或 Chrome 离线查看。

`src/template.html` 是制作页面的模板，不是看板入口。

## 使用方式

1. 顶部选择全量 1,000 人或排除待核对记录后重算的 915 人。
2. 使用人群、订阅等筛选项观察卡片与图表联动，或在散点图中框选用户。
3. 查看用户明细，搜索用户 ID，按得分排序并导出 CSV。
4. 调整浏览权重，比较同一名额下的入选名单。
5. 在收益区域调整购买率、券额和成本，查看预计净收益及敏感性；这些数值为情景假设。

清空筛选后可回到完整样本。数据口径与计算说明可从页面内的说明入口查看。

## 文件与更新

- `index.html`：可直接打开的成品。
- `src/`：页面模板、样式、交互代码与计算函数。
- `data/`：全量与重算后的用户数据。
- `vendor/`：本地 ECharts 图表库及许可。
- `build.py`：把上述内容打包成成品。
- `tests/`：交互计算相关检查。

在项目根目录运行 `python run_analysis.py` 可更新数据及看板。仅调整页面样式时，运行 `python dashboard/build.py`。

本看板展示的是规则评分与假设测算；用户得分不表示购买概率，预计收益不表示已产生收益。具体定义见 [模型说明](../reports/model_definition.md)。
